IgirePay Payment Gateway
IgirePay is a secure digital wallet and payment management system built using Java, JDBC, PostgreSQL, and Object-Oriented Programming principles.

Features
Customer Management
Wallet Account Management
Savings Account Management
Deposit and Withdrawal Processing
Money Transfers
Transaction History
Duplicate Transaction Prevention using Reference IDs
PIN Authentication
JDBC Database Integration
CSV Transaction Reports


Technologies Used.

PostgreSQL
